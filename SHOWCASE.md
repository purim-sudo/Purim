# Purim Labs Showcase

Purim Labs is a portfolio repository for practical software tools.

## What this repository shows

- Clean project structure
- Python utilities
- Node.js API work
- Automated tests
- Clear documentation
- Practical problem solving

## Projects

- PurimMonitor: small service status API
- SecureShare: temporary sharing API prototype
- NetWatch: local diagnostic helper
- LogLens: log summary helper
- PortalCheck: setup notes reviewer

## How to review it

Start with the root README, then open each project folder. The best order is PurimMonitor, SecureShare, LogLens, NetWatch, then PortalCheck.

## Portfolio message

This repository shows practical engineering: building small tools, testing them, documenting them, and organizing them for future growth.
