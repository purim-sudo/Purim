# Demo Guide

This guide gives a simple way to present the repository as a software portfolio.

## Suggested order

1. Start with the root README.
2. Open SHOWCASE.md for the short project summary.
3. Review PurimMonitor as the API service example.
4. Review SecureShare as the Node.js backend example.
5. Review LogLens as the log helper example.
6. Review NetWatch and PortalCheck as command-line utility examples.
7. Finish by showing the test commands and the CI workflow.

## What to say

Purim Labs is a collection of small practical tools. The projects show backend development, command-line utilities, testing, documentation, and repeatable checks.

## Strong talking points

- The repository is organized as a portfolio, not a single random project.
- Each project has a clear purpose.
- The code includes automated tests.
- The CI workflow helps confirm that changes remain working.
- The projects can be extended into real products later.
