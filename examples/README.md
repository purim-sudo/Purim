# Examples

This folder contains small sample files that make the projects easier to review.

## Contents

| Folder | Purpose |
| --- | --- |
| `loglens/` | Sample log input and expected summary output. |
| `portalcheck/` | Sample setup notes for checklist review. |
| `purimmonitor/` | Sample JSON response from the version endpoint. |
| `secureshare/` | Sample JSON response from the root endpoint. |

## Why examples are included

Examples help someone understand the projects quickly before running them locally.
They also make the repository easier to present as a portfolio.
