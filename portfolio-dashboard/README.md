# Portfolio Dashboard

This folder contains a simple static dashboard for presenting the Purim Labs repository visually.

## Open locally

Open this file in a browser:

```text
portfolio-dashboard/index.html
```

No build step is required.

## Purpose

The dashboard gives a quick visual summary of the repository projects:

- PurimMonitor
- SecureShare
- NetWatch
- LogLens
- PortalCheck

It is designed to help clients, recruiters, and collaborators understand the repository quickly.

## Possible next improvement

The dashboard can later be published with GitHub Pages so it becomes a public portfolio page.
